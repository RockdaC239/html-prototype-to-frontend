# 原型迁移验收参考

## CSS host boundary

- 原型 `:root` 变量放到组件根；`html/body/#app` 布局按职责映射到组件根，其他规则加稳定根作用域。
- 迁移后枚举通用 class，与原子 CSS、组件库和宿主规则求交集；在真实宿主读取 `display`、`position`、`overflow`、宽高和字体等计算样式。
- `table` 必须保持 table formatting context；select 使用 `appearance:none` 时必须同时迁移箭头；SVG 保留 viewBox、坐标、裁切、标签截断和比例算法。
- 比较组件内容宽度。宿主侧栏占用后的 1400px 内容区，应与 1400px 原型比较，而非与整个浏览器宽度比较。

## 数据与输出语义

- 动态页面先明确原型字段到目标数据字段的映射；稳定 ID、显示名称和实体关系分别处理。
- 保留指标的原始定义和统计范围；零、未知、缺失分别展示，不能从汇总数量虚构明细记录。
- 有分页或“全部”范围时依据已确认接口契约读取；不能把部分数据标成全量。筛选、详情和导出使用一致的数据范围。
- 关联状态或实体时用稳定 ID，不按数组位置或名称猜测。

## State matrix

按本次任务涉及的状态检查：

| Surface | Required observations |
|---|---|
| 默认页 | 区块/图表/表格顺序，默认 Tab 和筛选 |
| 空/单条/多条 | 轴域、标签、表格 colspan、滚动 |
| 长文本 | 截断、换行、title/完整信息入口 |
| 详情 | 导航 Tab 归属、所有信息行、附件、真实实体行 |
| 弹窗 | 初始值、焦点、取消、遮罩、Escape、失败重试、重复提交 |
| 窄屏 | 组件实际宽度、触控目标、横向滚动、宿主挤压 |
| 导出 | 下载 MIME/文件名、表头、行数、当前筛选、前导零和特殊字符 |

## Evidence artifact

需要复验或对外宣称像素级一致时，留下短文档或可重复脚本：基准版本、数据和时间、组件内容宽度、关键坐标或截图、已确认偏离项与未覆盖状态。验收 fixture 和测试工具不得从生产入口导入。
