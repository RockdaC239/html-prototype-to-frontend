# 迁移后的对齐与验收

适用于原型源码和目标页面均可运行时。先确定迁移范围，再选能暴露差异的状态验证；无需每改一处 CSS 就截全套图。

浏览器验证使用 `ego-browser`，不使用 Playwright。复用同一任务空间分别打开原型和目标页；结束后关闭本次打开的标签页并调用 `completeTaskSpace(..., { keep: false })`，不碰用户原有标签页。

## 比较前固定条件

| 条件 | 核对方式 |
| --- | --- |
| 源码版本 | 记录原型文件及目标提交或工作区状态，避免基准在比较中变化 |
| 入口 | 记录原型 URL 与真实应用 URL；微前端从宿主打开 |
| 尺寸 | 记录视口、缩放和页面组件根的实际内容宽度；宿主侧栏占宽时以内容宽度配对 |
| 字体与资源 | 确认字体、图片和 SVG 加载；字体回退会改变行高与换行 |
| 数据与时间 | 使用同口径样例，固定日期与时区，排除随机数和实时统计干扰 |
| 状态 | 记录 Tab、筛选、分页、弹窗和加载状态 |

例如原型内容区是 1400px，目标页在 1920px 浏览器中扣除侧栏后也是 1400px，这两个内容区才可直接比较。完整浏览器截图会把宿主外壳也算进去。

## 宿主与 CSS 边界

1. 核对根布局：原型 `html/body` 的背景、高度、滚动与间距应按职责映射到宿主容器或组件根；仅供该页使用的 `:root` 变量下沉到组件根。
2. 核对选择器作用域：`.card`、`.row` 等通用名称可能被宿主、组件库或原子 CSS 覆盖。在页面根下限定规则，并在真实宿主检查计算样式来源。
3. 核对元素替换：按钮、输入框、表格和列表有原生默认样式及语义。调整外观时保留焦点可见、标签和键盘操作。
4. 核对特殊布局：`table` 保留表格布局上下文；自定义 `select` 处理箭头；SVG 保留 `viewBox`、比例与裁切；图表沿用原型坐标、标签和空数据算法。

## 定位视觉差异

从外到内比较：组件根宽高与背景 → 主区块边界 → 栅格和间距 → 字体和换行 → 边框、阴影、图标。浏览器可读取元素矩形和计算样式：

```js
const element = document.querySelector('.page-root .summary-card');
const rect = element.getBoundingClientRect();
const style = getComputedStyle(element);
({ x: rect.x, y: rect.y, width: rect.width, height: rect.height,
  font: style.font, padding: style.padding, gap: style.gap });
```

将同一元素在原型与目标页的数值并排比较，追溯相应 DOM/CSS 规则。截图用于发现整体偏移、层叠、颜色和图表差异。需要“像素级”结论时，以同尺寸同状态截图记录差异区域与可接受偏差，不能只说“看起来一致”。

## 状态与行为矩阵

按任务范围选择，无需每个项目都具有全部功能。

| 场景 | 观察点 |
| --- | --- |
| 默认页 | 默认 Tab/筛选、区块顺序、图表与表格初始值 |
| 筛选与分页 | 结果范围、计数、空结果、翻页后状态与详情关系 |
| 空/单条/多条 | 空态、列宽、图表轴域与标签、滚动 |
| 长文本 | 换行/截断、行高、完整信息入口 |
| 详情与导航 | Tab 归属、字段、附件、稳定 ID 对应的实体 |
| 弹窗与表单 | 初始值、焦点、取消回滚、保存、失败重试、重复提交、Escape 和遮罩 |
| 窄屏 | 实际内容宽度、横向滚动、触控目标、弹窗溢出 |
| 导出或打印 | 当前筛选范围、表头、行数、文件名、编码、前导零和特殊字符 |

## 数据语义

- 建立字段映射：原型字段、目标字段、含义、单位、空值规则和来源。展示名称与稳定 ID 分开，关联与更新使用 ID。
- 统计卡片、图表、列表、详情和导出遵循同一筛选范围和统计口径。`0`、未知和缺失分别处理；不能从汇总数虚构明细。
- 接口分页时确认“全部”是否真的获得全部记录；只拿到当前页就只能表示当前页。接口不存在时按项目规则保留本地演示，明确它不代表正式数据。

## 交付记录

记录原型与目标版本、真实入口、浏览器与内容宽度、数据与时间、已验状态、关键矩形或截图、剩余差异、构建与测试结果。未经过的状态标为“未验证”。
